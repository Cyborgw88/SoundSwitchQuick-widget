# SoundSwitch Quick — Desktop Widget

Компактный hover-виджет для быстрого управления аудиовыходами Windows 11.

## Возможности v3

- один клик для переключения системного аудиовыхода;
- автоматическое раскрытие вверх или вниз в свободное место;
- автозапуск вместе с Windows, включаемый и отключаемый в настройках;
- тёмная и светлая тема;
- публичные названия устройств без изменения системных имён Windows;
- ⭐ избранные устройства и ручной порядок избранного;
- скрытие ненужных устройств из быстрого списка;
- «Все устройства» по отдельной кнопке, если настроены избранные;
- индивидуальное правило при подключении устройства: ничего / спросить / переключить автоматически;
- возврат на предыдущий выход, если автоматически выбранное устройство отключилось;
- громкость и mute прямо в карточке каждого устройства;
- колесо мыши над капсулой переключает избранные устройства;
- средняя кнопка мыши над капсулой включает / выключает звук;
- режим поверх остальных окон / обычный режим;
- создание ярлыка на рабочем столе;
- работа из трея.

## Сборка

Проект рассчитан на Windows x64 и .NET 8.

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

GitHub Actions автоматически публикует готовый `SoundSwitchQuick.exe` в artifact `SoundSwitchQuick-Windows-x64`.

## Настройки

Настройки хранятся в:

`%LOCALAPPDATA%\SoundSwitchQuick\widget-settings.json`

Автозапуск использует пользовательский Run key Windows и не требует прав администратора.

## Техническая заметка

Устройства, громкость и mute читаются через Windows Core Audio/MMDevice API с помощью NAudio.
Для назначения системного default endpoint используется PolicyConfig COM-интерфейс.

## v4 preview — запуск на мониторе или ТВ

1. Закройте прежний SoundSwitchQuick через пункт «Выход» в трее.
2. Поместите новый EXE в постоянную папку и запустите его.
3. ПКМ по значку в трее → «Экраны и запуск приложений».
4. Выберите монитор для первого запуска, включите контекстное меню и сохраните.
5. ПКМ по EXE / ярлыку → «Открыть на экране» → нужный экран и режим.
   В Windows 11 пункт находится в «Показать дополнительные параметры» (также Shift + ПКМ).
6. Следующие обычные запуски используют сохранённый экран, пока виджет работает.

Правило хранится по полному пути EXE и действует для разных ярлыков приложения.
Неизвестные приложения направляются на выбранный монитор. При отключении ТВ
используется монитор; предпочтение ТВ сохраняется. Окна, открытые до запуска виджета,
не перемещаются. Экран определяется по интерфейсному идентификатору устройства;
смена порта подключения или драйвера может потребовать повторного выбора.

Для ярлыка Steam / другого лаунчера при первом выборе нужно дождаться игрового окна,
нажать «Обновить» и выбрать EXE игры. Привязка ярлыка к игре сохраняется. Через трей
можно также применить правило к уже запущенному приложению. Если путь EXE игры
изменился, правило необходимо выбрать заново.

Настройки экранов: `%LOCALAPPDATA%\SoundSwitchQuick\display-routing.json`.
Диагностика: `display-routing.log` в той же папке. Настройки аудио остаются в прежнем
файле; модуль экранов не вызывает аудио API. Существующие звуковые правила v3 продолжают
работать как раньше.

### Границы preview

- Современное первое меню Windows 11 пока не реализовано; используется классическое.
- Окна обнаруживаются с задержкой около 1,2–1,6 секунды; возможно видимое перемещение.
- Применяется к новым основным окнам независимо от способа запуска, включая новые окна
  уже работающего приложения. Вспомогательные окна и известные лаунчеры исключены.
- Безрамочный режим рассчитан на оконные приложения. Эксклюзивный полноэкранный режим,
  защищённые игры и приложения с повышенными правами могут не подчиняться перемещению.
- Самопроизвольную смену экрана игрой после первоначального размещения модуль не подавляет.
- Для работы при двойном клике нужен запущенный виджет / включённый автозапуск.
- Перед переносом EXE в другую папку отключите меню, после переноса включите снова.
  Для удаления выключите контекстное меню и автозапуск, затем завершите виджет.

### Проверка на вашем ПК

- Новый EXE / два разных ярлыка одного EXE: первый запуск на мониторе.
- Выбор ТВ без рамок, закрытие, повторный запуск двойным кликом.
- Возврат на монитор через меню, восстановление рамки уже открытого окна.
- Отключённый ТВ: монитор; подключение ТВ и новый запуск: снова ТВ.
- Монитор слева от ТВ и разный масштаб DPI, например 125% / 200%.
- Ярлык Steam: однократное сопоставление с игрой и повторный выбор экрана.
- Перезапуск виджета: правила сохранены, старые окна не перемещаются.
- Аудиоустройство и громкость не меняются от команды выбора экрана.

Windows CI собирает EXE и запускает `--display-self-test`: выбор экрана, отключение и
возврат ТВ, сериализация правил, регистр пути, исключение лаунчера, native-перечисление
экранов, реальное снятие и восстановление рамки тестового окна и его размер на экране.
Проверку двух физических экранов и совместимость с конкретными играми CI не заменяет.
